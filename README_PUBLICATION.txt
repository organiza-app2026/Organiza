ORGANIZA — PROJET ANDROID

Ce dossier est un projet source Android Studio qui emballe l'application Organiza dans une application Android.

OUVRIR
1. Installer Android Studio sur un ordinateur.
2. Décompresser Organiza_Android.zip.
3. Dans Android Studio, choisir Open puis sélectionner le dossier Organiza_Android.
4. Laisser Gradle synchroniser le projet.
5. Tester avec Run sur un téléphone ou un émulateur.
6. Pour produire un fichier de publication : Build > Generate Signed Bundle / APK.
   Pour Google Play, choisir Android App Bundle (AAB), puis créer une clé de signature et la conserver en sécurité.

IMPORTANT AVANT UNE PUBLICATION PUBLIQUE
- Ce projet est un prototype local. Il ne comporte pas encore de serveur pour un compte utilisateur, une vraie IA ou des paiements Premium.
- Le tarif affiché (4,50 €/mois) est indicatif : aucun paiement n'est traité.
- Le verrou Premium par note de 5 étoiles est une logique de démonstration, pas un système de paiement.
- Avant Google Play : ajouter une politique de confidentialité réelle, compléter la fiche Play Console, fournir les captures d'écran et l'icône, tester sur plusieurs appareils et vérifier les règles Google Play.
- La publication elle-même nécessite un compte Google Play Console et n'est pas effectuée par ce projet.
- Le package actuel est fr.organiza.app ; change-le avant publication si tu veux un identifiant différent et unique.
